## Overview

A hackathon to build the best-performing AI program to control a sentry turret. I engineered the NLP module that converts human transcriptions into standardised instructions.

A lightweight LLM combined with pre/post regex processing and Pydantic schemas gave a very fast model capable of function calling with near-perfect accuracy, directly contributing to the team's 1st runner-up finish.

## Reflection

My first exposure to deploying models with Docker images and containers.
