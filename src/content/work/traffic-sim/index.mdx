## Overview

Classic traffic models use fixed rules for route choice. This simulation asks what happens when every driver is an LLM agent with its own personality. On a real 1 km² road network around Bugis, Singapore, each agent checks the congestion ahead every 12-second step and decides in plain language whether to stay on its route or reroute.

The project was later scaled up into HoloCity: a 2 km slice of Singapore with 500 agents, a replayable timeline, and live breakdowns of what agents are doing, how they travel and where they go.

## How it works

- Road network built with OSMnx from OpenStreetMap, with lanes, speeds and capacity per road; congestion modelled with the BPR delay function
- Five demographic groups (students, professionals, elderly, families, young professionals), each with its own ranges for income, urgency, comfort and cost sensitivity
- Trips from preset origin–destination pairs or chosen by the LLM to fit the persona; routes planned with A*
- Agents built on Google ADK with tools to read their own profile and analyse the route ahead, running gpt-oss:20b locally on Ollama
- Ray actors hold agent sessions and Ray tasks move agents in parallel, behind a load balancer for the local LLM
- Points of interest from OpenStreetMap and bus stops and routes from Singapore's LTA DataMall ground the map in real data
- Output is an interactive Leaflet map with timestep playback, colour-coded delays and agent markers
