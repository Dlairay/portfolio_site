## Overview

EncoreWorks is a two-sided marketplace that matches experienced professionals with companies hiring for fractional and interim roles. Companies often undervalue senior talent; the platform surfaces what people can really do and carries the whole flow from match to application, messaging, reference checks and billing.

I was the lead contract engineer, building the product essentially solo from the first commit to a production launch, then handing it over to the client's team.

## AI that stays honest

The core problem is understanding skills people have but don't write down. I built a multi-pass inference pipeline for it:

- CV extraction that only records skills the CV actually states
- Latent skill inference: profile fields become evidence atoms, an LLM proposes candidate skills, and a skill graph proposes related ones
- Every inferred skill has to pass an LLM defensibility check, then resolve against a curated skills registry — so the AI never invents vocabulary
- A golden-set eval harness with gates on recall, precision and zero certification leaks, run before changes ship
- Prompt-injection guards, a circuit breaker with retries, rate limits and a per-user daily LLM cost ledger

## Matching & platform

Matches combine a normalised capability-fit score with a five-dimension leadership calibration and an industry boost, computing the top matches for both sides. Around that sits a full product: multi-seat company accounts, messaging with attachments and meeting invites, moderation, Stripe billing and PDPA-compliant data export and deletion.

## Engineering

FastAPI with async SQLAlchemy on Google Cloud Run; a Next.js 16 / React 19 frontend on Vercel; Supabase Postgres with row-level security. Three fully separate environments (local, staging, production) with promotion from staging to production, around 1,900 backend tests, Playwright tests that drive only the real UI, and custom validators that catch schema drift, hardcoded settings and mock data before they ship.
